## 🌟 Featured Projects

### 📦 [Axiom-ml](https://github.com/tammam-bt/Axiom-ml)
A lightweight machine learning and deep learning library built entirely **from scratch using NumPy** and distributed via PyPI. Designed with a professional `src/` layout, it avoids high-level frameworks to implement core algorithmic mechanics explicitly.
- **Key Features:** Full feedforward neural networks, decision trees, linear regression, and logistic regression engines.
- **Tech:** Python, NumPy, PyPI Packaging.

### 🤖 Eurobot Autonomous Navigation Architecture
A low-level hardware-software integrated control stack designed for competitive autonomous mobile robots.
- **Key Features:** Real-time motor control and path tracking using custom PID/MPC loops executing on STM32 microcontrollers, integrated natively with sensor fusion and navigation pipelines running on **ROS2 Jazzy** and Raspberry Pi 5.
- **Tech:** C++, C, ROS2 Jazzy, STM32, Embedded Linux.

### 📊 [TuniCompare](https://github.com/tammam-bt/TuniCompare)
A heavy-duty price aggregation and hardware comparison engine evaluating the Tunisian IT retail market.
- **Key Features:** High-resiliency ETL web scraping pipelines that continuously extract, normalize, and relationalize complex hardware specs into a scalable PostgreSQL backend.
- **Tech:** Python, Flask, PostgreSQL, Advanced Web Scraping.
